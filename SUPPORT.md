# Support

- Bugs: use the GitHub bug report form with a minimal reproduction.
- Product ideas: use the feature request form.
- Security issues: follow `SECURITY.md`; never open a public security issue.
- General questions: use GitHub Discussions after it is enabled.

VISOR is beta software and community support is best effort. Include the VISOR
version, operating system, architecture, GPU vendor, and the exact sensor or
runtime that is unavailable. Remove usernames and sensitive paths from logs.
